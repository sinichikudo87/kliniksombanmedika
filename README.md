# Aplikasi Bridging BPJS Kesehatan — Klinik Somban Medika

Aplikasi ini dikembangkan untuk mengintegrasikan sistem manajemen operasional Klinik Somban Medika dengan layanan API Bridging BPJS Kesehatan. Didesain untuk mempercepat antrean, sinkronisasi data rekam medis/pendaftaran, serta validasi peserta secara real-time.
